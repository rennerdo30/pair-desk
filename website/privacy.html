Privacy

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public GitHub API for the newest Pair Desk release, so the install section can name it. GitHub receives that request like any other visit to GitHub. The site is hosted on GitHub Pages, which logs visitor IP addresses in its own server logs; see the GitHub privacy statement.

Pair Desk

Pair Desk runs on your computer and has no account and no telemetry. Its server listens on 127.0.0.1 only, and everything it stores stays in one data folder on your machine. It sends nothing anywhere unless you turn on Git project sharing, which pushes the projects you choose to a data branch in a Git repository you name, with that repository's own authentication.
